# Sources du skill KiCad GEII

Archive locale personnelle du site CAO GEII Lyon 1, collectée le 16 novembre 2026. Les cours restent attribués à leurs auteurs ; cette copie n'est pas publiée.

Contenu local : 12 pages HTML, 6 fichiers téléchargeables du site, 39 images, bibliothèques de symboles et d'empreintes. Le cours PDF contient 64 pages. Les 14 liens PDF externes ont été essayés séparément : 11 récupérés, 3 indisponibles.

Les feuilles CSS, scripts de présentation, installateurs KiCad, dépôts de bibliothèques externes et contenus des playlists ne sont pas archivés. Les liens restent conservés dans l'inventaire initial ; aucun contenu YouTube oral n'a été transcrit.
