# Raccourcis du cours

Source : [page Raccourcis](http://geii.pages.univ-lyon1.fr/cao/raccourcis/). Vérifier les préférences clavier de l'installation réelle si une touche diffère.

| Action dans le schéma | Touche |
|---|---|
| Retour à la sélection | Échap |
| Ajouter un symbole / alimentation | A / P |
| Tracer un fil | W |
| Déplacer / déplacer avec les liens | M / G |
| Rotation / miroir horizontal / vertical | R / X / Y |
| Éditer | E |
| Texte graphique | T |
| Rechercher | Ctrl+F |

| Action dans le PCB | Touche |
|---|---|
| Commencer une piste | X |
| Mode routage de piste simple | Maj+X |
| Changer de couche et placer un via en routage | V |
| Origine relative | Espace |
| Déplacer une piste à 45° / angle quelconque | D / G |
| Déplacer / tourner un composant | M / R |
| Sélectionner les segments entre pastilles | U |
| Sélectionner les pistes du nœud | I |
| Recentrer l'ensemble du schéma | Début / Home |

Le double-clic ouvre les propriétés. Un déplacement avec conservation des liens n'est pas équivalent à un déplacement libre : vérifier le chevelu et le DRC après l'opération.
